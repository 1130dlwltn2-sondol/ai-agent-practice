# 32. 에이전트 간 통신

여러 에이전트가 함께 일하면 서로 정보를 주고받아야 합니다.

가장 단순한 방식은 코디네이터를 통하는 것입니다. 서브에이전트들은 서로 직접 말하지 않고, 코디네이터에게 보고합니다. 코디네이터가 필요한 정보를 전달합니다. 구조가 단순하고 추적하기 쉽습니다.

다른 방식은 공유 저장소입니다. 에이전트들이 공통의 작업 공간에 결과를 씁니다. 다른 에이전트가 읽어 씁니다. 파일이나 데이터베이스가 이 역할을 합니다. 각자 자기 속도로 일할 수 있습니다.

직접 통신은 피하는 것이 좋습니다. 에이전트끼리 직접 메시지를 주고받으면 흐름을 따라가기 어렵습니다. 디버깅이 힘들어집니다. 꼭 필요할 때만 쓰고, 로그를 남깁니다.

통신에서 정할 것들입니다. 누가 무엇을 언제 공유하는지 정합니다. 형식은 통일합니다. 서브에이전트의 출력 형식이 다르면 코디네이터가 합치기 어렵습니다. 실패한 경우의 전달도 정합니다. 에러가 났을 때 어떻게 알릴지 미리 정합니다.

핵심 정리
- 코디네이터를 통하거나 공유 저장소를 쓰는 것이 기본이다.
- 직접 통신은 피하고, 쓰면 로그를 남긴다.
- 출력 형식을 통일하고 실패 전달 방식을 정한다.
