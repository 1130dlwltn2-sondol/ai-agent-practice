# 22. 병렬화

병렬화는 독립적인 작업을 동시에 처리하는 패턴입니다. 서로 의존하지 않는 일들을 한 번에 합니다.

예를 들어 보겠습니다. "이 제품의 장단점을 조사해줘"를 하면, 장점 조사와 단점 조사를 동시에 합니다. 두 작업은 서로 영향을 주지 않으니 기다릴 필요가 없습니다. 결과가 모이면 하나로 합칩니다.

이 패턴이 좋은 경우입니다. 작업들이 서로 독립적일 때입니다. 전체 시간을 줄이고 싶을 때입니다. 여러 관점의 결과를 모아야 할 때입니다.

두 가지 방식이 있습니다. 나누기 방식은 하나의 작업을 여러 관점으로 나누어 동시에 처리합니다. 투표 방식은 같은 작업을 여러 번 해서 결과를 비교합니다. 중요한 판단에서는 투표 방식이 안전합니다.

설계 요령입니다. 정말 독립적인지 확인합니다. 겉보기에 독립 같아도 순서가 필요한 경우가 있습니다. 결과를 합치는 단계를 따로 둡니다. 합치는 프롬프트가 결과를 정리합니다. 병렬 수를 너무 늘리면 비용이 급증하니 적정선을 찾습니다.

핵심 정리
- 독립적인 작업을 동시에 처리해 시간을 줄인다.
- 나누기 방식과 투표 방식이 있다.
- 결과를 합치는 단계를 따로 두고 병렬 수를 조절한다.
