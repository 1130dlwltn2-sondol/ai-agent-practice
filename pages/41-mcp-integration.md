# 41. MCP 연동

MCP는 에이전트에게 도구를 주는 표준 방식입니다. MCP 서버를 만들면, 여러 에이전트 도구에서 그대로 씁니다.

에이전트 개발에서 MCP가 좋은 이유입니다. 도구를 한 번 만들면 여러 클라이언트에서 씁니다. Claude Code에서 만든 도구를 Cursor에서도 씁니다. 도구의 표준 설명 형식이 있어서, 에이전트가 이해하기 쉽습니다. 원격 MCP 서버로 팀 전체가 같은 도구를 씁니다.

연동 방법입니다. 로컬에서 쓰는 도구는 stdio MCP 서버로 만듭니다. 에이전트 설정에 서버를 등록합니다. 팀이 함께 쓰는 도구는 원격 MCP 서버로 만듭니다. OAuth로 보호하고 URL로 연결합니다. 자세한 방법은 MCP 실전 가이드를 참고하세요.

에이전트에 MCP를 쓸 때의 요령입니다. 필요한 서버만 연결합니다. 너무 많으면 에이전트가 헷갈립니다. 서버별로 역할을 나눕니다. 검색 서버, DB 서버 같은 식입니다. 중요한 도구는 승인 설정을 켭니다.

MCP를 쓰면 도구 개발과 에이전트 개발이 분리됩니다. 도구 팀은 MCP 서버를 만들고, 에이전트 팀은 그것을 씁니다. 협업이 깔끔해집니다.

핵심 정리
- MCP는 에이전트에게 도구를 주는 표준 방식이다.
- 한 번 만들면 여러 클라이언트에서 쓴다.
- 필요한 서버만 연결하고 중요한 도구는 승인을 켠다.
