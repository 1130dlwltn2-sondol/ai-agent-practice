# 12. 에이전트의 구성 요소

에이전트는 세 가지로 구성됩니다. 모델, 도구, 환경입니다.

모델은 판단하는 두뇌입니다. 상황을 보고 다음 행동을 정합니다. 어떤 모델을 쓰느냐에 따라 에이전트의 능력이 달라집니다. 복잡한 판단에는 강한 모델을, 단순한 반복에는 가벼운 모델을 씁니다.

도구는 손과 발입니다. 검색, 계산, 파일 읽기, API 호출 같은 것입니다. 모델은 말을 하지만, 실제 행동은 도구를 통해 합니다. 도구가 좋아야 에이전트가 일을 합니다. 도구 설계는 Part 4에서 자세히 다룹니다.

환경은 에이전트가 보고 듣는 세상입니다. 대화 기록, 파일, 웹 페이지 같은 것입니다. 에이전트는 환경을 관찰하고 행동합니다. 환경이 바뀌면 다시 관찰하고 다음 행동을 정합니다. 이 관찰과 행동의 반복이 에이전트의 기본 동작입니다.

여기에 하나를 더합니다. 목표입니다. 에이전트에게 무엇을 해야 하는지 명확히 줍니다. 목표가 모호하면 에이전트도 헤맵니다. "고객 문의를 분류해줘"보다 "고객 문의를 환불, 배송, AS로 분류하고, 확신이 80% 미만이면 사람에게 넘겨줘"가 낫습니다.

이 네 가지를 종이에 적어 보세요. 내가 만들 에이전트의 모델, 도구, 환경, 목표가 무엇인지. 설계의 시작입니다.

핵심 정리
- 에이전트는 모델, 도구, 환경으로 구성된다.
- 모델은 판단하고, 도구는 행동하고, 환경은 관찰 대상이다.
- 목표는 구체적으로 줄수록 에이전트가 잘 돈다.
