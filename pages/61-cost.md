# 61. 비용 관리

에이전트는 돈이 듭니다. 비용을 관리해야 오래 씁니다.

비용이 나가는 곳입니다. 모델 호출이 가장 큽니다. 강한 모델을 많이 부를수록 비쌉니다. 도구 호출도 비용입니다. 검색 API 같은 것은 건당 과금이 있습니다. 길어지는 대화는 컨텍스트 비용을 올립니다.

줄이는 방법입니다. 첫째, 모델을 나눠 씁니다. 복잡한 판단에만 강한 모델을 쓰고, 단순한 작업에는 가벼운 모델을 씁니다. 분류는 가벼운 모델로 충분합니다. 둘째, 캐시를 씁니다. 같은 질문이 반복되면 답을 저장해 둡니다. 셋째, 단계를 줄입니다. 불필요한 단계를 없앱니다. 체이닝이 길수록 비쌉니다. 넷째, 일찍 끝냅니다. 답이 나오면 멈춥니다. 계속 돌리지 않습니다.

비용을 봅니다. 요청당 평균 비용을 계산합니다. 어느 단계에서 많이 쓰는지 봅니다. 예산을 정합니다. 하루나 한 달 상한을 둡니다. 넘으면 알림을 받습니다.

비용과 품질의 균형입니다. 무조건 줄이면 품질이 떨어집니다. 중요한 곳에는 쓰고, 줄일 곳은 줄입니다. 평가와 함께 봅니다. 비용을 줄였는데 통과율이 떨어지면 안 됩니다.

핵심 정리
- 모델을 나눠 쓰고, 캐시를 쓰고, 단계를 줄인다.
- 요청당 비용을 보고 예산 상한을 둔다.
- 비용을 줄여도 평가 통과율은 지켜야 한다.
