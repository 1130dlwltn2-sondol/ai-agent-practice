# AI 에이전트 실전 개발

AI 에이전트를 직접 설계하고 만드는 실전서입니다.

AI 에이전트는 2026년 AI 산업의 중심 트렌드입니다. 단순히 답을 내놓는 챗봇을 넘어, 도구를 쓰고 계획을 세우며 일을 끝까지 해내는 시스템이 에이전트입니다. 이 책은 에이전트와 워크플로우의 구분부터, 5가지 워크플로우 패턴(프롬프트 체이닝, 라우팅, 병렬화, 오케스트레이터-워커, 평가자-최적화), 멀티 에이전트 오케스트레이션, 도구 설계와 MCP 연동, 세션 상태 관리, 평가와 가드레일, 휴먼인더루프, 운영과 모니터링까지 다룹니다.

책의 마지막에는 고객 문의 처리 에이전트를 만드는 실전 프로젝트와 확인 문제 20문항, 상세 해설을 수록했습니다.

- 대상 독자: 에이전트를 처음 만드는 개발자부터, 운영 중인 에이전트를 개선하려는 엔지니어까지
- 기준일: 2026-10-09
- 구성: 첫 페이지, 책 소개, 전체 목차, Part 1~6 본문 20개 장, 실전 프로젝트, 확인 문제, 마무리
