# AI 에이전트 실전 개발

에이전트를 처음 만드는 개발자부터 운영 중인 시스템을 개선하려는 엔지니어까지, 에이전트로 만들 일과 워크플로우로 처리할 일을 구분하고 설계·평가·운영을 연결하는 실전서입니다.

## 누구를 위한 책인가요?
- 대상 독자: AI 에이전트 입문 개발자, 에이전트의 실패·안전·비용을 개선하려는 엔지니어
- 수준: 입문 → 워크플로우 설계 → 멀티 에이전트·도구 연동 → 평가·안전·운영 → 실전 프로젝트

## 무엇을 배우고 만드나요?
- 에이전트와 워크플로우를 구분하고 프롬프트 체이닝·라우팅·병렬화·오케스트레이터-워커·평가자-최적화 패턴을 익힙니다.
- 멀티 에이전트 오케스트레이션, 세션 상태 관리, 에이전트 간 통신과 실패 대처를 설계합니다.
- 도구 설계·MCP 연동, 평가·가드레일·휴먼인더루프, 운영·비용 관리를 연결합니다.
- 결과물: 고객 문의를 분류하고 정책 문서·배송 조회 도구로 답변하며, 확신이 낮거나 위험한 요청은 사람에게 넘기는 고객 문의 처리 에이전트

## 실전 프로젝트
환불·배송·AS·기타 문의를 라우팅하고 종류별 처리 경로를 만듭니다. 배송 조회 API와 정책 문서를 연결하고, 분류 확신이 80% 미만인 문의는 사람에게 넘깁니다. 환불 승인에는 사람의 확인을 두고, 테스트 케이스 30개·입출력 가드레일·성공률·사람 개입 비율·요청당 비용으로 평가와 운영까지 이어갑니다.
